📝 Note Space

A simple space for your thoughts, ideas, and notes.

Note Space is a note-taking application I'm currently building with modern web technologies. The goal is to create a clean and simple place where users can securely manage their notes.

«🚧 Status: Work in Progress»

---

✨ Features

- 🔐 User Authentication ✅
- 📝 Create and manage notes
- ✏️ Edit notes
- 🗑️ Delete notes
- 🔎 Search notes
- 📂 Organize notes
- 📱 Responsive design

---

🛠️ Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Prisma
- PostgreSQL

---

🎯 Goal

The goal of Note Space is to build a simple, secure, and beautiful note-taking application while practicing real-world full-stack development.

---

🛣️ Development

The project is currently under development. More features and improvements will be added as development continues.
